# راهنمای تبلیغات و اطلاعیه‌ها

همه‌ی نسخه‌های نصب‌شده‌ی Neo Uptime تبلیغ‌ها را از فایل [`ads.json`](../ads.json) همین مخزن می‌خوانند و در این جاها نشان می‌دهند:

| جا | نام در فایل | توضیح |
|---|---|---|
| بالای داشبورد | `dashboard` | کارت بزرگ با عنوان، متن و دکمه؛ کاربر می‌تواند آن را برای ۳ روز ببندد |
| منوی کنار پنل | `sidebar` | کارت کوچک با عنوان و دکمه |
| اسکریپت نصب و منوی آن | `install` | داخل ترمینال، بعد از نصب یا آپدیت |

## چطور تبلیغ را عوض کنم؟

۱. در گیت‌هاب فایل `ads.json` را باز کنید و روی آیکون مداد (Edit) بزنید.
۲. تبلیغ را تغییر دهید و **Commit changes** را بزنید.
۳. پنل‌ها حداکثر ظرف چند ساعت تبلیغ جدید را می‌گیرند (هر پنل هر ۳ تا ۳٫۵ ساعت یک بار می‌خواند).

بعد از هر تغییر، تست خودکار گیت‌هاب (CI) فایل را بررسی می‌کند. اگر علامت قرمز ✗ دیدید، فایل ایراد دارد؛ پنل‌ها تبلیغ ایرادی را نشان نمی‌دهند و نسخه‌ی قبلی را نگه می‌دارند.

## نمونه

```json
{
  "ads": [
    {
      "id": "vpn-offer-1405-07",
      "lang": "fa",
      "placements": ["dashboard", "sidebar", "install"],
      "badge": "تبلیغ",
      "title": "سرور مجازی آلمان با تخفیف ۳۰٪",
      "text": "مناسب تانل BackPack و Kariz، تحویل فوری.",
      "button": "خرید",
      "url": "https://t.me/neoaurora",
      "color": "#22c55e",
      "start": "2026-10-12",
      "end": "2026-11-12",
      "weight": 2
    }
  ]
}
```

## فیلدها

| فیلد | لازم؟ | توضیح |
|---|---|---|
| `id` | بله | شناسه‌ی یکتا. برای تبلیغ جدید `id` جدید بگذارید تا برای کسانی که قبلی را بسته‌اند هم دوباره نشان داده شود |
| `title` | بله | عنوان، حداکثر ۹۰ حرف |
| `text` | خیر | توضیح، حداکثر ۲۸۰ حرف |
| `button` | خیر | متن دکمه، حداکثر ۳۰ حرف |
| `url` | خیر | لینک دکمه (`https://…` یا `tg://…`) |
| `lang` | خیر | `fa` یا `en`؛ خالی یعنی برای هر دو زبان پنل |
| `placements` | خیر | کجا نشان داده شود؛ خالی یعنی همه‌جا |
| `badge` | خیر | برچسب کوچک بالای تبلیغ؛ خالی یعنی «تبلیغ» |
| `color` | خیر | رنگ دکمه و لبه، مثل `#22c55e` |
| `start` / `end` | خیر | از چه روزی تا چه روزی (میلادی، `2026-10-31`) |
| `weight` | خیر | وقتی چند تبلیغ هست، عدد بزرگ‌تر یعنی بیشتر نمایش داده شود (پیش‌فرض ۱) |

چند تبلیغ را می‌شود کنار هم گذاشت؛ هر بار یکی از آن‌ها (با توجه به `weight`) انتخاب می‌شود. برای اسکریپت نصب بهتر است یک نسخه‌ی انگلیسی (`"lang": "en"`) هم بگذارید، چون خیلی از ترمینال‌ها فارسی را درست نشان نمی‌دهند.

برای حذف همه‌ی تبلیغ‌ها فایل را این‌طور بگذارید: `{"ads": []}`.
